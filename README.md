# iml-jev-gate（Jev 安检）

WorkBuddy 每次执行命令之前，先过一道安检：有风险的拦下来，等你点了「放行」才执行。

配套文章：《WorkBuddy 默认权限也会漏，我让 Jev 补了一道安检》，公众号「AI产品康Sir」。

## 用之前先知道

| 事项 | 说明 |
|---|---|
| 它是什么 | 个人写的脚本，没做过对抗测试，别把它当安全产品 |
| 在哪测过 | macOS，WorkBuddy 5.5.6，默认权限；Windows 没测过 |
| 会不会失效 | 它用的是 WorkBuddy 的钩子，这个功能还在测试阶段，升级后行为可能变 |
| 数据去哪 | 要判断的命令会在打码之后发到 Jev 的境外接口；介意的话不要填密钥，只用本地规则 |
| 需要什么 | Python 3.9 以上和 curl，macOS 都自带 |

## 下载

```bash
git clone https://github.com/imoling/iml-jev-gate.git
cd iml-jev-gate
```

没装 git 的话，在仓库页面点绿色的 Code 按钮，选 Download ZIP，解压后在终端里进入那个目录。

## 三步装上

在上面那个目录里依次执行。

**第一步：填密钥。** 没有密钥可以跳过，见下面「没有密钥也能用」。

```bash
python3 install.py --set-key
```

**第二步：挂到一个工作目录上。** 把路径换成你自己的。

```bash
python3 install.py --scope project --dir ~/WorkBuddy/你的工作目录
```

**第三步：看看接通没有。**

```bash
python3 install.py --check
```

看到「Jev 已接通」就好了。在 WorkBuddy 里新建一个任务，工作空间选刚才那个目录，让它删一个不要的文件试试。

## 密钥

### 去哪拿

到 TypeSafe 的控制台 `console.typesafe.ai` 申请。Jev 目前是限量早期访问，要排队。

### 怎么填，怎么换

```bash
python3 install.py --set-key
```

粘贴密钥后回车，输入时屏幕上不显示。以后要换，再运行一次，新的会盖掉旧的。换完下一条命令就生效，不用重启 WorkBuddy。

密钥存在 `~/.workbuddy/iml-jev-gate/.env`，只有你本人可读。

也可以手动改。用文本编辑器打开这个文件，没有就新建，里面只写一行：

```
TYPESAFE_API_KEY=你的密钥
```

手动新建的话，再执行一次 `chmod 600 ~/.workbuddy/iml-jev-gate/.env`。

### 为什么不用环境变量

WorkBuddy 是从图形界面启动的，你在终端里 `export` 的变量它读不到。所以密钥以文件为准。

### 没有密钥也能用

不填密钥，安检只靠本地规则：

| 情况 | 处理 |
|---|---|
| 下载后直接执行、删整个个人目录、抹磁盘 | 直接拒绝 |
| 命令里有删除、联网、改权限这类操作 | 要你确认 |
| 命令涉及工作目录之外的路径 | 要你确认 |
| 命令可能覆盖已有文件 | 要你确认 |
| 其余 | 放行 |

这时弹窗括号里写的是「没接 Jev」。本地规则只认字面，比 Jev 粗。

### 两件要当心的事

- `.env` 别发给别人。要把脚本转给朋友，发仓库地址，别打包你自己的 `~/.workbuddy/iml-jev-gate/` 目录
- 密钥别写进命令行参数，会留在终端历史里

## 弹窗长什么样

```
Jev 安检（中风险）：会删除已有文件。要放行这条命令吗：rm ./tmp_convert.log
  1 放行
  2 取消
```

括号里有四种写法：

| 括号里 | 意思 |
|---|---|
| 低、中、高风险 | Jev 判的 |
| 命中规则 | 本地规则拦的 |
| Jev 没响应 | 填了密钥，但这次没等到回话，按本地规则处理 |
| 没接 Jev | 没填密钥 |

不想点弹窗，直接在对话里回一句「放行」也行，整句话只能有这两个字。

放行有几条限制：

| 限制 | 说明 |
|---|---|
| 只认那一条命令 | 命令变了要重新确认 |
| 只认最近一次 | 你之后说了别的，放行作废 |
| 会过期 | 15 分钟 |
| 高危规则不给放行 | 确实要执行的话，自己到终端里跑 |

## 调松紧

改 `~/.workbuddy/iml-jev-gate/config.json`，保存后下一条命令生效。

| 键 | 含义 | 默认 |
|---|---|---|
| `ask.exfil` | 「会把本机数据发到外部」超过多少要确认 | 0.5 |
| `ask.deletes` | 「会删除已有文件」 | 0.8 |
| `ask.overwrites` | 「会覆盖已有文件」 | 0.8 |
| `ask.outside` | 「会改动工作目录之外的内容」 | 0.6 |
| `ask.irreversible` | 「执行后难以撤销」 | 0.65 |
| `ask.off_task` | 「看起来和当前任务无关」 | 0.8 |
| `ask.risk` | 风险分到多少算中风险，满分 3 | 1.5 |
| `timeout_seconds` | 等 Jev 多少秒 | 7 |
| `approval_minutes` | 放行多久过期 | 15 |
| `send_task` | 是否把你最近一条指令的前 300 字发给 Jev，用来判断离不离题 | true |
| `display_name` | 弹窗开头显示的名字 | Jev 安检 |

嫌它问得多，就把对应的数调大；嫌它放得松，就调小。

## 查记录

每次判断都记在 `~/.workbuddy/iml-jev-gate/decisions.jsonl`。想看汇总：

```bash
python3 gate_report.py --last 30
```

它会把安检的判断和 WorkBuddy 自己的审计日志按命令对起来，只读本地文件，不联网。

## 卸载

```bash
python3 install.py --scope project --dir ~/WorkBuddy/你的工作目录 --uninstall
```

想连脚本、密钥和记录一起清掉，再删掉 `~/.workbuddy/iml-jev-gate/` 这个目录。

## 会发出去什么

| 内容 | 发不发 |
|---|---|
| 要执行的命令 | 发，先打码 |
| 工作目录的路径 | 发，用户名换成 `~` |
| 命令里提到的文件存不存在 | 发 |
| 你最近一条指令的前 300 字 | 发，可以关 |
| 文件内容 | 不发 |
| 只读命令、被本地规则拦下的命令 | 不发 |

打码会换掉：长得像密钥的字符串、邮箱、手机号、用户名。

## 已知情况

| 项 | 状态 |
|---|---|
| 挂在单个工作目录上，桌面端能触发 | 测过 |
| 弹窗放行，默认权限 | 测过 |
| 弹窗放行，允许完全访问 | 没测 |
| 用 `--scope user` 挂到所有任务 | 没在桌面端测过，要用的话先在一个目录上试几天 |
| 发消息、付款这类连接器工具 | 没接，默认只管命令 |
| Jev 超时 | 测试那天 29 次里遇到 2 次，会转本地规则处理 |

## 常见问题

| 现象 | 原因和办法 |
|---|---|
| 装了没反应 | 要新开任务才生效；任务的工作空间要选挂了安检的那个目录 |
| 没弹窗，只有一段文字让我确认 | 模型这次没用提问工具；直接回一句「放行」 |
| 点了放行又问一遍 | 它重新发出的命令和刚才不一样；再确认一次 |
| 命令变慢了 | 要问 Jev 的命令多等 1 到 4 秒；只读命令不受影响 |
| `--check` 显示 http 401 | 密钥不对，重新 `--set-key` |
| `--check` 显示 http 000 | 网络连不上 Jev，检查网络或代理 |
| 无害的操作也被拦 | 把对应的阈值调大，见「调松紧」 |
